DOT APP — Privacy Policy
Effective date: November 10, 2026 · Last updated: November 10, 2026

This Privacy Policy explains what information the DOT APP Discord bot and its website dashboard (the "Service") collect, how we use it, and the choices you have. By using the Service, you agree to this policy.

1. Information we collect
Discord identifiers and public profile data. We collect user IDs, server (guild) IDs, channel IDs and role IDs. When we need to show information, we also use usernames, display names and avatars as Discord provides them.

Data you or your server create by using features. This includes:

server settings that administrators configure, such as the prefix, welcome and goodbye messages, auto-roles, logging, auto-moderation rules, tickets, AI settings and auto-responses;
leveling data: XP, level and message counts (counts only, not message content);
economy data (balance, bank, reputation, inventory items, cooldown timestamps) and the profile data you set (bio, color);
moderation records: for each warning, the user ID, moderator ID, reason and time;
giveaway entries, ticket records (channel, opener, time), reminders (text and time), starboard and counting state, and temporary voice channel ownership;
command usage counts: the command name and number of uses, not linked to any user.
Message content. DOT APP reads message content in real time only to run features that you or your server turned on: commands, auto-moderation, auto-responses, counting, AI chat and logging. Message content is not stored in our database. If a server turns on logging, deleted and edited messages are posted to that server's own log channel. When a ticket is closed, a transcript is posted to the server's ticket log channel, if the server has set one up.

Dashboard sign-in. When you log in with Discord, we receive your user ID, username, avatar and the list of servers you are in (through the identify and guilds scopes). This information stays only in an encrypted session cookie in your browser and is not stored in our database. We never receive your email or password.

2. How we use information
We use information only to operate, secure and improve the Service. That means running commands and features, saving server settings, showing levels and leaderboards, checking dashboard permissions, preventing abuse and fixing bugs. We do not sell, rent or trade your data, and we do not use it for advertising.

3. Third parties
Discord: the platform the Service runs on.
AI provider (an OpenAI-compatible API chosen by the bot operator): we contact it only when you use AI features, such as mentioning the bot, writing in an AI channel, or using /ask, /translate or /summarize. We send the relevant message text and your display name so it can generate a reply. A short history of the last few messages is kept in memory only. It is cleared when the bot restarts or when you use /resetai.
Image generation service: only the prompt you type in /imagine is sent.
Audio sources: the search terms and links you give music commands are used to find and stream audio.
GIF service: only the type of action (for example "hug") is requested. No personal data is sent.
4. Data retention
We keep data while we need it to provide the Service:

Server settings stay until the server removes them or someone asks us to delete them.
Leveling, economy and warning records stay until an administrator or the owner resets them, or someone asks us to delete them.
In-memory data (AI conversation history, music queues, cooldowns) is cleared when the bot restarts.
5. Security
We store data in a private database on the bot's server and keep secrets in environment variables. Dashboard sessions are signed and encrypted. No storage method is 100% secure, but we take reasonable steps to protect your data.

6. Your rights and choices
You can stop using the Service at any time. Server administrators can remove the bot, and can reset settings, levels and warnings from the dashboard.
You can ask us for a copy of the data linked to your user ID or server, or ask us to delete it. Contact the bot owner on Discord: 4_m. We will respond within 30 days.
7. Children
The Service is not meant for children under the minimum age Discord requires in their country. We do not knowingly collect data from such users.

8. Changes
We may update this policy. The "Last updated" date above shows when it last changed. If you continue to use the Service after changes, you accept the updated policy.

9. Contact
For questions or requests, contact the bot owner on Discord: 4_m.
